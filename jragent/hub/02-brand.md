# 02 · 品牌卷宗
## 策略体检所 StrategyClinic

---

## 一、命名

**中文名**：策略体检所
**英文名**：StrategyClinic
**简称**：体检所

### 为什么叫"体检所"

| 考量 | 说明 |
|---|---|
| 价值直观 | 体检 = 诊断，不是开药方。我们出检查报告，不替用户做决定 |
| 降低恐惧 | 去医院体检是日常行为，量化策略体检同理 |
| 价格自然 | 9.9 元做一次体检，用户不需要被教育 |
| 合规友好 | 天然避开"荐股""带单"的联想 |

### 不叫什么，以及为什么

- ❌ 不叫"XX 量化"：听起来像专业机构，新手会觉得自己不是目标用户
- ❌ 不叫"XX 智能选股"：直接踩荐股红线
- ❌ 不叫"XX AI 炒股"：同上，且显得不严肃

> 注意：国内 A 股配色为**涨红跌绿**，与欧美相反。
> 全站统一，不要混用。

### 2.2 字体与排版

- 中文：苹方 / 微软雅黑
- 数字：`font-variant-numeric: tabular-nums`，保证表格数字对齐
- 正文字号 14px，行高 1.65
- 圆角：卡片 12px，按钮 8px

### 2.3 界面原则

**轻、留白、少颜色。**
金融产品最容易做得"很吵"，我们反着来：
- 每屏只突出一个动作
- 不用渐变、不用阴影堆叠、不用动效炫技
- 风险提示用浅底说明条，不用弹窗打断

## 三、语调规范

### 3.1 三句话定位语气

1. **像朋友，不像老师**——不教育用户，只给事实
2. **像医生，不像销售**——说"检查结果是……"，不说"这个产品很好"
3. **说人话**——术语必须紧跟一句白话解释

### 3.2 用词对照表

| 不要说 | 改成 |
|---|---|
| 该策略年化收益率达 X% | 过去一年每年大约赚 X% |
| 最大回撤 | 最难受的时候账户亏了多少 |
| 夏普比率 | 每承担一分波动，能换回多少收益 |
| 策略表现优异 | 这段时间里它赚了 X% |
| 建议您买入 | 历史数据是这样，要不要用你自己定 |
| 量化交易 | 用规则自动做买卖决定 |
| 回测 | 拿过去的数据试跑一遍 |

### 3.3 必须有的表达习惯

- **跑输必须说**，且要放在显眼位置，不能藏在段尾
- **数字必须带基准**：只说"赚 18%"是误导，要说"赚 18%，同期拿着不动是 63%"
- **样本量必须带**：胜率后面要跟交易次数，否则 100% 胜率就是误导

## 五、标语（slogan）

**主标语**：
> 你的策略，到底靠不靠谱？

**备选**：
- 跑输了，我们会明说
- 别的工具教你怎么用，我们告诉你该不该用
- 说人话的量化体检

**使用场景**：
- 主标语用于落地页首屏与登录页
- "跑输了，我们会明说"用于分享页与获客内容末尾
- 禁止在任何标语中出现收益承诺

## 六、对外物料规范

### 6.1 获客内容三要素

每条内容必须包含：
1. **一个真实数字**（来自我们的回测，不编造）
2. **一个反直觉结论**（金叉在茅台亏钱、100% 胜率只有 6 次交易）
3. **一个行动入口**（"你也可以测一下自己的策略"）

### 6.2 发布前检查（闸门④）

- [ ] 没有禁词
- [ ] 数字真实，能在库里复现
- [ ] 没有荐股表述
- [ ] 老板已看过并点头

---

## 七、品牌一致性检查

任何 Agent 产出对外内容前，必须能回答：
1. 这句话像是在帮用户，还是在推销？
2. 这个数字有没有来源？
3. 这个结论有没有同时给出反面信息（基准、回撤、样本量）？

三条有一条答不上来，打回重写。
