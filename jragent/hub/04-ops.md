## 一、AI 员工编制与汇报关系

```
                    老板（唯一人类）
                          │  只做三个决策：定价 / 人事 / 上线
                          ▼
                    COO Agent（总编排）
                    拆任务、派活、收结果、卡节点、升级
                          │
      ┌───────────┬───────┴───────┬───────────┬──────────┐
      ▼           ▼               ▼           ▼          ▼
   研究 Agent  产品 Agent      内容 Agent   客服 Agent  风控 Agent
   市场调研    回测引擎        获客文案     答疑工单    合规审查
   竞品分析    策略诊断        发布排期     风险定级    禁词拦截
                                                      （有一票否决权）
                          │
                          ▼
                      财务 Agent
                      记账、毛利、周报、对账
```

**汇报规则**：所有 Agent 只向 COO 汇报，COO 向老板汇报。
**风控 Agent 有独立否决权**，可越过 COO 直接打回任何产出，不需要逐级上报。

### 闸门⑥ 为什么用人工核销而不是自动支付

这不是技术妥协，是**合规要求 + 团队能力的共同答案**：

1. 蓝图明确要求"资金动作必须老板执行/确认"
2. 微信/支付宝商户号需要企业或个体户主体，个人无法申请
3. 自动回调涉及验签、证书轮换、防重放，团队无人具备相关经验

**钱完全不经过系统**，因此没有回调伪造的攻击面。唯一风险是用户谎称已付款，
而老板低头看一眼手机就是核验机制。

演示时这句话要原样说：
> 「所有资金动作都必须我本人确认，Agent 只负责准备材料，不做终裁。」

## 三、异常处理 SOP（出错谁兜底）

### 3.1 通用三级降级

```
任务执行
  → 失败：自动重试第 1 次（间隔 5 秒）
  → 仍失败：自动重试第 2 次（间隔 15 秒）
  → 仍失败：降级到备用路径（换 prompt / 换工具 / 用模板）
  → 仍失败：标记 ESCALATED，升级老板，不空转、不硬答
```

**每一次失败都写入 `agent_runs` 表**，字段含重试次数、错误信息、最终状态。
这张表既是人事档案的数据源，也是事故报告的数据源。

### 3.2 三个具体场景

| 场景 | 处理 |
|---|---|
| AI 诊断报告含违规词 | 风控 Agent 打回 → 附带违规词位置 → 重写 → 最多 3 轮 → 仍不过则降级为模板报告 |
| 回测数据不足 | 不返回空结果，明确告知"该标的数据不足 30 根 K 线"，并建议换标的 |
| MiMo API 调用失败 | 预扣积分全额退回（`fail_release`），用户不损失积分，页面提示稍后再试 |

### 3.3 演示用的"故意失败"

演示脚本 1:30–2:15 需要展示一次失败重试。预定构造方式：

> 让 AI 诊断报告里出现"这个策略稳赚"，
> 风控 Agent 命中禁词"稳赚" → 打回并标注位置 → 重写 → 第二次通过。
> 日志里留下两条 `agent_runs` 记录：一条 FAILED，一条 SUCCESS。

这是真实机制，不是表演。禁词表见下文第四节。

## 四、合规禁词表（风控 Agent 用）

### 4.1 一票否决级（出现即打回）

```
稳赚 / 保本 / 必涨 / 必赚 / 躺赚 / 包赚 / 无风险
 guaranteed / 内幕 / 消息股 / 庄家 / 拉升在即
现在买入 / 现在卖出 / 满仓 / 清仓 / 梭哈
包你赚 / 亏损包赔 / 收益保证
```

### 4.2 需要改写级（提示更稳妥的表述）

| 出现 | 改成 |
|---|---|
| 这个策略能赚钱 | 这段历史区间里该策略收益为 X%，同期买入持有为 Y% |
| 推荐买入 | 历史回测显示……是否采用由你判断 |
| 收益很高 | 收益为 X%，同时最大回撤为 Y% |
| 没有风险 | 任何策略都有回撤风险，本策略历史最大回撤为 X% |

### 4.3 每份 AI 报告必须附带的三句话

```
1. 历史表现不代表未来，回测收益通常高于实盘。
2. 本报告为技术工具输出，不构成投资建议。
3. 数据截至 {latest_trade_date}，T 日数据于收盘后次日更新。
```

## 六、客服 FAQ（阶段 5 文档占位版）

**Q：你们会告诉我买哪只股票吗？**
不会。我们只验证策略的历史表现，不推荐任何具体买卖。

**Q：回测赚钱，实盘就能赚吗？**
通常不能。回测没有包含全部滑点与情绪因素，历史表现不代表未来。

**Q：积分能退吗？**
积分不可提现、不可转让。未消耗的充值可申请人工处理，走闸门⑦。

**Q：我的数据截至哪天？**
每份报告顶部都标注了数据截止日期，一律为最近一个已收盘交易日。

**Q：AI 会不会给我写一个独家策略？**
不会。AI 只在已有的策略框架内调整参数，不生成新的策略代码。

**Q：为什么这个策略回测跑输了还推荐给我看？**
因为让你知道"它跑输了"正是我们的价值。我们不会只展示好看的曲线。
