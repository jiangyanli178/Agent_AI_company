## 1. 一句话定位

**一家由 1 个人 + 6 个 AI 员工运营的量化策略工作室，把机构级的策略验证流程，做成散户买得起的按次服务。**

我们卖的不是"哪个股票会涨"，是"**你这个策略到底靠不靠谱**"。

---

## 2. 公司形态

| 项 | 内容 |
|---|---|
| 人类员工 | 1 人（老板，兼 CEO / 合规终审 / 资金确认） |
| AI 员工 | 6 个：研究、产品、内容、客服、风控、财务 |
| 公司大脑 | 本 Context Hub（9 卷宗），所有 Agent 读写同一份事实 |
| 产品形态 | H5 Web 应用，手机浏览器可用，不做 App |
| 收费方式 | 积分制，按次扣费，预付费 |

## 3. 目标用户

**主要**：对量化好奇但完全不会编程的个人投资者。

他们的真实处境：
- 听过"金叉死叉"，但不知道这玩意儿历史上到底灵不灵
- 上网搜到的都是"这个策略年化 30%"的帖子，无从验证
- 聚宽、米筐这类平台要学编程，第一道门槛就把他们挡住了
- 他们**只想知道一件事：这个方法靠不靠谱**

**次要**：会写一点策略、但懒得搭回测环境的半专业用户。

**明确不服务**：追求高频、实盘自动化、机构级数据的用户。我们不做，也不假装能做。

---

## 4. 价值主张

| 用户痛点 | 我们的回答 |
|---|---|
| 看不懂回测 | 你说人话，AI 去找策略、跑回测、把结果翻译成人话 |
| 怕被帖子骗 | 所有结论必须来自真实回测，**跑输买入持有会明说** |
| 不知道风险 | 每个报告都带最大回撤、涨跌停无法成交次数 |
| 不想先学编程 | 全程对话，不需要写一行代码 |

**核心差异**：别的工具回答"怎么用"，我们回答"**该不该用**"。

## 6. 红线（不可突破，任何 Agent 违反即打回）

1. **不荐股**。不预测未来涨跌，不输出"现在买 / 现在卖"的指令。
2. **不承诺收益**。禁止出现"稳赚""保本""必涨""躺赚"等表述。
3. **不代客下单、不接触客户资金**。所有部署均为模拟盘。
4. **AI 不编写策略代码**。只能在已有的策略框架内调整参数。
5. **不伪造数据**。用户评价、订单数、营收、回测结果必须真实产生，禁止编造。
6. **跑输必须说**。回测结果不如买入持有时，不得淡化、不得只报喜。
7. **积分不可提现、不可转让、不可兑换现金**。
8. **密钥不进对话**。API key、数据库密码只存在于 `.env`，不出现在任何 prompt 与卷宗正文。
9. **用户数据最小化**。只收集手机号，不收集身份证、真实姓名、住址。

## 7. 人工闸门① · 立案决策记录

| 项 | 内容 |
|---|---|
| 决策事项 | 做什么生意 |
| 候选方向 | A 多 Agent 投资人格（多头/空头辩论）<br>B 量化策略工作坊（表单式）<br>C 对话式策略体检所 |
| 淘汰 A 的原因 | 属于"展示 Agent 编排"，是赛题明确的扣分项；且无真实客户与闭环 |
| 淘汰 B 的原因 | 与聚宽、米筐同构，没有降低门槛，差异化不足 |
| **选定** | **C 对话式策略体检所** |
| 选定理由 | 对话是降低门槛的唯一路径；每一次对话都有真实产出物；合规风险可控 |
| 拍板人 | 老板本人 |
| 备注 | Agent 只提供候选与依据，本决策不由 Agent 作出 |

## 8. 命名说明（为什么叫"体检所"）

- **直接说明价值**：体检 = 诊断，不是开药方。天然避开"荐股"联想
- **降低心理门槛**：生病去医院体检是日常行为，量化策略体检同理
- **价格锚点自然**：9.9 元做一次体检，用户不需要被教育
- **合规叙事顺畅**：我们出具的是"检查报告"，结论由用户自己判断
