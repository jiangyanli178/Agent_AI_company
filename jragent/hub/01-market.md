# 01 · 市场调研与竞品
## 策略体检所 · 阶段 0 立案产出

> 本卷宗回答：这门生意为谁做、凭什么有人付钱、和谁抢用户。

---

## 一、目标人群

### 1.1 核心画像

**对量化好奇、但不会编程的个人投资者。**

典型状态：
- 炒股 1-5 年，看过"金叉买死叉卖"这类文章
- 听说过量化，觉得"那是程序员才能玩的东西"
- 在聚宽、米筐注册过，被代码编辑器劝退
- 真正想知道的只有一句话：**这个方法到底灵不灵**

### 1.2 他们不想要什么

| 不要 | 原因 |
|---|---|
| 学 Python | 第一道门槛就劝退 |
| 看一堆指标术语 | 看不懂就等于没说 |
| "十大经典策略"清单 | 看完了还是不知道哪个适合自己 |
| 保证收益的荐股 | 被骗过，不信 |

### 1.3 他们愿意为什么付钱

**为一个确定的答案付钱，而不是为一个工具付钱。**

"你这个策略在茅台上市值亏了 27%"这句话，比任何功能列表都有价值。
这就是我们把单次诊断定价 9.9 元的依据——它低到不需要犹豫。

## 二、竞品对照

| 产品 | 形态 | 门槛 | 我们的差异 |
|---|---|---|---|
| **聚宽 JoinQuant** | 在线 IDE + 回测框架 | 必须会写 Python | 我们全程对话，零代码 |
| **米筐 RiceQuant** | 同上，偏机构 | 同上 | 同上 |
| **BigQuant** | 可视化拖拽 + AI | 仍需理解因子概念 | 我们用大白话解释结果 |
| **TradingView** | 图表 + Pine 脚本 | 要学英语和脚本 | 中文、A 股、无需编程 |
| **同花顺/东财 选股器** | 条件筛选 | 无回测验证 | 我们给历史净值曲线 |
| **雪球/知乎 帖子** | 经验分享 | 无法验证真伪 | 我们每个结论都来自真实回测 |

### 核心空档

> **会写代码的人不缺工具，不会写代码的人没有工具。**

现有产品都在服务前者。我们服务后者。

### 我们不做的事

- 不做高频、不做分钟级数据
- 不做实盘自动交易
- 不做因子编辑器、不做组合回测
- 不做机构级数据服务

**边界清晰，才可能在 24 小时内做完。**

## 三、定价带分析

| 产品 | 价格 | 对比 |
|---|---|---|
| 聚宽专业版 | 约 3000 元/年 | 我们的目标用户不会买 |
| TradingView Pro | 约 $15/月 | 需要英文与外汇场景 |
| 知识星球量化圈 | 199-999 元/年 | 卖的是观点，无法验证 |
| **我们 体验包** | **9.9 元/次** | **一杯奶茶的零头** |
| **我们 标准包** | **49 元** | 一顿饭钱 |

**定价逻辑**：不是和量化平台抢同一批用户，
而是把"验证一个策略"这件事的价格，打到**普通人不用思考就能付**的区间。

## 四、真实数据支撑的需求证据

我们自己跑出来的结果（见 `docs/真实回测结果_演示素材.md`）：

| 现象 | 说明的问题 |
|---|---|
| 均线交叉在茅台五年 **-27.68%** | 流传最广的方法，在最知名的股票上失效 |
| 基准买入持有 **-9.03%** | 盲目操作比拿着不动多亏 18 个百分点 |
| RSI 收益 43.81%、胜率 100%、**仅 6 次交易** | 新手最容易被"高胜率"误导 |
| 同一只票四策略差异 **超 70 个百分点** | 选哪个策略比"要不要量化"重要得多 |

**这四个数字就是市场需求的直接证据**：
如果普通投资者能方便地看到这些，很多人会改变做法。

## 五、获客渠道判断

| 渠道 | 适配度 | 理由 |
|---|---|---|
| **小红书** | ★★★★★ | 理财新手聚集，"金叉亏了 27%"这种标题有传播力 |
| **知乎** | ★★★★ | 适合长文拆解"为什么回测好看实盘亏钱" |
| **雪球** | ★★★★ | 用户精准，但对"荐股"敏感，我们只讲验证不讲买卖 |
| 抖音/B站 | ★★★ | 需要视频制作能力，本次不做 |
| 微信群 | ★★★★ | 分享链接直接裂变，是我们的主要出口 |

**主渠道**：小红书 + 知乎 + 分享链接裂变。

## 六、风险与限制（诚实记录）

| 风险 | 影响 | 应对 |
|---|---|---|
| 标的池只有 30 只 | 覆盖不全 | 明确告知，后续扩充 |
| 标的池有幸存者偏差 | 回测偏乐观 | **答辩时主动承认**，并指出池内含万科、隆基等大幅回撤标的 |
| 只有日线 | 无法做日内策略 | 明确不做，写入产品边界 |
| 回测不含完整滑点模型 | 实盘收益会更低 | 每份报告强制附带提示 |
| 数据来自公开接口 | 稳定性不可控 | 每日落库，本地计算，断网可用 |
