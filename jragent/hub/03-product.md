# 03 · 产品卷宗
## 策略体检所 · 产品说明与验收标准

---

## 一、产品是什么

一个对话式的策略验证工具。
用户用大白话提问，AI 负责找策略、跑真实回测、把结果翻译成人话。

**核心差异**：别的工具回答"怎么用"，我们回答"**该不该用**"。

### 3.2 降级实现

| 功能 | 降级为 | 原因 |
|---|---|---|
| 部署 | 观察列表（我的回测记录） | 调度运维成本高，演示价值低 |
| 实盘 | 不做 | 合规与工期均不允许 |
| 欢迎邮件 | 充值成功页 + 新手引导卡 | SMTP 配置成本高 |

### 3.3 明确不做

高频数据、分钟级回测、实盘对接、积分提现、任意代码执行。

> 注：早期版本把「多因子组合」「用户自定义代码」也列为不做，现已实现——
> 因子组合走组合搜索，自定义因子走**受限表达式**（只能用四则运算和 9 个白名单函数，
> 不能 import、不能比较、不能访问属性），既开放又不执行任意代码。

### 3.4 数据导出（2026-11-07 新增）

用户的数据应该能拿走，不用留在我们这儿当筹码：

| 导出内容 | 入口 | 格式 |
|---|---|---|
| 标的日线原始数据 | 策略详情页「下载日线数据」 | CSV（带 BOM，Excel 直接打开不乱码） |
| 因子逐日取值 | 因子弹窗「下载逐日数据 CSV」 | CSV |
| 回测明细（净值+交易+口径说明） | 策略详情页「下载回测明细」 | ZIP 内 3 个文件 |

全部在内存里拼好直接响应，服务器不留临时文件。

### 3.5 联网搜索（可选开关）

AI 可以去网上找因子/策略线索，但**搜回来只当线索**，必须写成公式跑回测才算数。

配置方式：`.env` 里填 `WEB_SEARCH_PROVIDER`（tavily / bocha / serper）+ `WEB_SEARCH_API_KEY`。
不配也能用，此时 AI 会明确说"现在没有联网能力，以下是我模型记忆里的内容"。

## 四、技术边界（为什么这些限制是刻意的）

| 限制 | 理由 |
|---|---|
| AI 只输出"框架 + 参数" | 不执行 AI 写的代码，安全且可复现 |
| 回测与部署共用同一引擎 | 避免"回测一套逻辑实盘另一套" |
| 数据截至 T-1 | 当天未收盘的半根 K 线不参与计算 |
| 前复权数据 | 除权日的假跳空会让均线信号全错 |
| 涨跌停不可成交 |  naive 回测最大的虚高来源 |
| 核心模块零重型依赖 | 回测与账本只用标准库，现场不会装包失败 |

## 五、验收标准（DoD）

### 5.1 产品可用性

- [x] 外网可访问（穿透后验证）

- [x] 前复权日线，无脏数据

### 5.3 合规性

- [x] 无收益承诺表述
- [x] 每份报告附免责声明
- [x] 风控 Agent 有一票否决权
- [x] 资金动作必须人工确认

### 5.4 商业闭环

- [x] 定价公开，四档套餐
- [x] 真实收款可完成
- [x] 积分消耗有完整流水
- [x] 单位经济可实时计算
- [x] 账目可自查

## 六、已知限制（答辩时主动说）

1. **标的池 30 只**，且存在幸存者偏差，回测结果偏乐观
2. **只有日线**，无法验证日内策略
3. **滑点模型简化**，实盘收益通常低于回测
4. **参数优化存在过拟合风险**，工具已强制附加警告
5. **无真实交易**，全部为历史回测与模拟信号

**主动承认限制，比被评委问出来好。**
