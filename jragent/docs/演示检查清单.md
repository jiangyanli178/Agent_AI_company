## 三、三分钟演示脚本

### 0:00–0:30 ｜ 公司大脑

打开 `hub/` 目录：

> 「我们是一家一人公司，一个老板加六个 AI 员工。
> 这是公司大脑，九个卷宗，所有 Agent 共用同一份事实。
> 这是人工闸门清单——定价、发布、收款，都必须我本人确认。」

**不要一上来就演示产品**，否则评委会以为这只是一个工具。

### 0:30–1:30 ｜ 现场跑一单

1. 请一位观众说一句话，例如"给我一个能用的策略"
2. AI 自动找策略、跑真实回测、返回对比卡片
3. 强调：**「跑输买入持有它会明说，这是它和别的工具的区别」**
4. 现场充值 9.9 元 → 展示收款码 → **你手动确认到账**
5. 打开积分流水：「每一分钱都有记录」

### 1:30–2:15 ｜ 故意失败一次

让 AI 输出一句含"稳赚"的话（可用测试输入诱导），
合规 Agent 命中禁词 → 打回 → 重写 → 通过。

打开 `agent_runs` 或看板的异常记录：
> 「风控有一票否决权，每次打回都留痕。
> 这不是表演，是我们真实的异常处理机制。」

### 2:15–2:45 ｜ 一键周报

```bash
python scripts/weekly_report.py
```

展示：GMV、付费用户、积分消耗结构、真实 token 成本、毛利、agent 绩效、**账目自查**。

> 「余额必须等于流水求和，系统每天自己查一遍账。」

### 2:45–3:00 ｜ 收尾

> 「一个人，一支 AI 团队，跑通了从提问到收款再到复盘的完整闭环。
> 我们的产品不告诉你买什么，只告诉你**你的策略靠不靠谱**。」

## 四、评委可能问的问题与应答

**Q：这跟聚宽有什么区别？**
> 聚宽服务会写代码的人，我们服务不会写代码的人。
> 他们说"给我一个策略"，我们的 AI 会去跑真实数据，而不是给他一段代码。

**Q：AI 会乱说怎么办？**
> 两层约束：一是只能调工具拿真实数据，不许空谈；
> 二是风控 Agent 有一票否决权，违规表述会被打回重写。

**Q：回测准吗？**
> 我们做了三件别人不做的事：前复权数据、信号延后一天防未来函数、涨跌停不可成交。
> 光涨跌停这一条，实测就差了 46 个百分点。
> 同时我们主动承认标的池有幸存者偏差。

**Q：合规吗？**
> 不推荐买卖、不代客下单、不接触资金，只做策略验证工具。
> 资金动作必须我本人确认。

**Q：怎么赚钱？**
> 积分制，回测 10 积分、诊断 30 积分，检索永久免费。
> 单用户月成本约 3 元，毛利约 89%。盈亏平衡只要每月 1.6 个付费用户。

## 五、如果现场崩了

| 情况 | 处理 |
|---|---|
| 穿透断了 | 切手机热点，重启隧道；不行就放录屏 |
| 数据库挂了 | 用备份恢复，或直接放录屏 |
| AI 响应慢 | 「它在跑真实回测」，同时打开历史回测报告继续讲 |
| 完全起不来 | 放录好的 3 分钟视频 + 用 PPT 截图讲完 |

**核心原则：演示可以降级，但不能冷场。**
