# 内网穿透操作指引
## 没有云服务器也能让评委打开产品

---

## 一、为什么用穿透

评分要求"产品可访问"。穿透会把你的本地服务映射成一个公网 URL，
评委手机扫码就能打开，效果等同于有云服务器。

**不需要备案，10 分钟搞定。**

---

## 二、推荐方案：cpolar 固定域名（约 20 元/月）

### 为什么建议花这 20 元

免费版的域名**每次重启都会变**。你要把链接印进 PPT 和二维码，
变一次就要全部重做。20 元消掉这个变量，值得。

### 步骤

1. 到 cpolar 官网注册，下载 Windows 客户端
2. 购买一个**固定二级域名**（保留隧道）
3. 本地启动后端后，执行：

```bash
# 后端 API
cpolar http 8000

# 前端（开发模式）
cpolar http 5173
```

4. 把分配的固定域名配到隧道上，得到：
   - 前端：`https://你的域名.cpolar.cn` → 给评委打开的链接
   - 后端：`https://api-你的域名.cpolar.cn` → 前端要请求它

### 前端指向后端

开发时走 Vite 代理，上线后需要改 `frontend/src/api/index.js`：

```js
const api = axios.create({
  baseURL: 'https://api-你的域名.cpolar.cn/api',   // 原来是 '/api'
  timeout: 120000,
})
```

改完重新 `npm run build`，用 Nginx 或静态托管展示 `dist/`。

**更简单的方式**：前后端走同一个域名，用路径区分——
`https://你的域名/` 给前端，`https://你的域名/api` 给后端。
cpolar 支持按路径转发，配一条规则即可，这样前端代码一行都不用改。

## 三、免费方案（不花钱）

### 步骤

```bash
cpolar http 5173        # 前端
cpolar http 8000        # 后端
```

每次会分配一个随机域名，形如 `https://xxxx.cpolar.top`。

### 必须注意

- **二维码不要提前印**，现场投屏生成
- **演示当天只启动一次，中途不要重启**
- 重启后域名会变，之前发的链接全部失效

## 四、穿透前必须检查的安全项

```
□ MySQL 不要暴露 3306（已验证 root@localhost，外部无法认证）
□ 不要穿透 phpMyAdmin 或任何数据库管理界面
□ 不要穿透 .env 所在目录
□ /api/admin/* 已设 ADMIN_PHONE，非老板手机号打不开
□ 生产环境把 FastAPI 的 docs_url 关掉（backend/app/main.py）
```

关闭文档的方法：

```python
app = FastAPI(
    docs_url=None,
    redoc_url=None,
    openapi_url=None,
)
```

**开发期保留，穿透前改。**

## 六、常见问题

**Q：手机能打开但一直转圈？**
多半是前端请求后端走了 `localhost`。检查 `baseURL`，手机上的 localhost 是手机自己，不是电脑。

**Q：AI 回答特别慢？**
穿透免费版限速，正常。可以先预热一次，让首次请求完成后再演示。

**Q：提示跨域？**
把穿透域名加进后端 `.env` 的 `CORS_ORIGINS`，多个用逗号分隔。

**Q：隧道频繁断开？**
关掉 VPN，换手机热点。公司网络常会拦穿透协议。
